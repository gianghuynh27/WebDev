# Productivity Dashboard Skeleton

This repo includes a full app and a separate skeleton scaffold under `src/skeleton/`.

## File structure

- `src/skeleton/App.tsx` — entry-page navigation to demo pages
- `src/skeleton/main.tsx` — Vite entry file
- `src/skeleton/index.css` — basic styling
- `src/skeleton/types/index.ts` — shared type definitions
- `src/skeleton/hooks/` — reusable hook stubs
- `src/skeleton/components/` — component stubs for each app feature
- `src/skeleton/pages/` — page shells for dashboard, timers, todos, and form

## How to use

Open the `src/skeleton/` files and build each feature from the stubbed structure.

The skeleton is intentionally minimal, so you can fill in the implementation details yourself.
